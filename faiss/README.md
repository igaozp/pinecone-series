# FAISS 系列文章

本目录包含从 Pinecone 网站提取的 FAISS (Facebook AI Similarity Search) 系列教程文章。

## 系列概述

FAISS 是 Facebook AI Research 开发的用于高效相似性搜索和密集向量聚类的库。本系列文章深入介绍了 FAISS 的各个方面，从基础概念到高级索引技术。

## 章节列表

1. **Chapter 01: Introduction to Facebook AI Similarity Search (Faiss)**
   - 文件: `chapter01.md`
   - 介绍 FAISS 库的基础知识和使用方法

2. **Chapter 02: Nearest Neighbor Indexes for Similarity Search**
   - 文件: `chapter02.md`
   - 讲解最近邻索引在相似性搜索中的应用

3. **Chapter 03: Locality Sensitive Hashing (LSH): The Illustrated Guide**
   - 文件: `chapter03.md`
   - 图解局部敏感哈希算法

4. **Chapter 04: Random Projection for Locality Sensitive Hashing**
   - 文件: `chapter04.md`
   - 介绍随机投影在 LSH 中的应用

5. **Chapter 05: Product Quantization: Compressing high-dimensional vectors by 97%**
   - 文件: `chapter05.md`
   - 讲解乘积量化技术及其压缩效果

6. **Chapter 06: Hierarchical Navigable Small Worlds (HNSW)**
   - 文件: `chapter06.md`
   - 介绍 HNSW 算法及其在向量搜索中的应用

7. **Chapter 07: Facebook AI and the Index Factory**
   - 文件: `chapter07.md`
   - 讲解 FAISS 索引工厂的使用
